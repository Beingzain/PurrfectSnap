## 🚀 What's New in the Litterbox?

<details closed>
<summary> 🎨 Revamped Theming Engine </summary>

- **AMOLED theme**: A gorgeous, battery-saving theme for the Snapenhance menu.
- **Fresh Coat of Paint**: Restored icons (like the beloved gear ⚙️) and a polished UI.
</details>

<details closed>
<summary> 📱 Dynamic Bottom Bar </summary>

- **Total Control**: Add or remove tabs to create a layout that works for you.
- **Default Tab**: Set your own preferred landing tab on startup.
</details>

<details closed>
<summary> 📍 Advanced Trackers & Catalogs </summary>

- **Friend Tracker**: Seamlessly import and export your tracked friends list.
- **Built-in Catalogs**: Discover new customizations with integrated catalogs for both **Friend Tracker** and **Scripts**.
</details>

<details closed>
<summary> ⚙️ Intelligent Tools & Internals </summary>

- **Haptic Feedback**: Optional tactile feedback for a more responsive experience.
- **Modern Internals**: Updated dependencies for maximum performance and stability.
</details>
